# 新概念英语学习打卡

一个基于 Flutter 的新概念英语学习打卡应用，支持 Android 和 iOS 双端，采用 Duolingo（多邻国）游戏化设计风格 —— 鲜艳色块、标志性 3D 立体按钮、活泼粗体字体。

## 下载安装

前往 [Releases 页面](../../releases) 下载最新版本安装包：

| 平台 | 文件 | 安装方式 |
|---|---|---|
| Android | `.apk` | 直接安装 |
| iOS | `.ipa` | 需使用 [Sideloadly](https://sideloadly.io/) / [AltStore](https://altstore.io/) / TrollStore 自签后安装 |

## 软件介绍

### 核心功能

- 按天学习与打卡，每 2 课为 1 天，单数新课 + 双数复习
- 三阶段任务体系：预习 → 正式学习 → 复习，每项可勾选标记完成
- 支持新概念英语第一、二、三册，教材切换互不干扰
- 完成当天全部任务后播放全屏仪式感动画

### 单词学习

- 按天推送当天生词列表，含音标和释义
- 认识 / 不认识滑动复习，不认识的自动加入生词本
- 生词本随时查看、管理、删除
- 英音 / 美音 TTS 单词发音
- 认识 / 不认识按钮本地音效反馈

### 成就系统

- 连续打卡成就（7 天 / 14 天 / 30 天）
- 教材通关成就（新概念 1 / 2 / 3 全部完成）
- 成就解锁时弹出庆祝动画

### 日历打卡

- 日历视图直观展示打卡记录
- 支持补打卡（选择历史日期补签）
- 打卡日高亮标记

### 界面设计

- Duolingo（多邻国）游戏化视觉语言，鲜艳活泼
- 主色 Duo Green #58CC02，辅以橙/蓝/红/紫/黄功能色
- **标志性 3D 立体按钮**：亮色顶面 + 深色底边，按下时下沉凹陷
- 干净卡片：白/深底 + 细描边 + 柔和阴影 + 圆角
- 底部胶囊导航，选中项绿色填充 + 3D 立体感
- 多彩渐变勋章 + 鲜艳统计网格
- 深色 / 浅色模式无缝切换

### 数据存储

- 纯本地 Hive 存储，无需联网，无需账号
- 学习进度、打卡记录、生词本、成就全部本地保存

## 技术栈

- Flutter 3.10+
- Hive 本地存储
- audioplayers 音效播放
- flutter_tts 文字转语音

## 云端编译

项目配置了 GitHub Actions 自动编译：

- 推送到 `main` 分支后自动构建 APK 和 IPA
- 每次构建自动顺延版本号
- 构建完成后自动创建 GitHub Release 并上传安装包
- 也可在 [Actions 页面](../../actions) 手动触发
