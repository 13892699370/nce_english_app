# 新概念英语学习打卡

一个基于 Flutter 的新概念英语学习打卡应用，支持 Android 和 iOS 双端，采用 iOS 26 透明玻璃（Liquid Glass）设计风格。

## 下载安装

前往 [Releases 页面](../../releases) 下载最新版本安装包：

| 平台 | 文件 | 安装方式 |
|---|---|---|
| Android | `.apk` | 直接安装 |
| iOS | `.ipa` | 需使用 [Sideloadly](https://sideloadly.io/) / [AltStore](https://altstore.io/) / TrollStore 自签后安装 |

## 软件介绍

### 核心功能

- 按天学习与打卡，每 2 课为 1 天，单数新课 + 双数复习
- 三阶段任务体系：预习 → 正式学习 → 复习，每项可勾选标记完成
- 支持新概念英语第一、二、三册，教材切换互不干扰
- 完成当天全部任务后播放全屏仪式感动画

### 单词学习

- 按天推送当天生词列表，含音标和释义
- 认识 / 不认识滑动复习，不认识的自动加入生词本
- 生词本随时查看、管理、删除
- 英音 / 美音 TTS 单词发音
- 认识 / 不认识按钮本地音效反馈

### 成就系统

- 连续打卡成就（7 天 / 14 天 / 30 天）
- 教材通关成就（新概念 1 / 2 / 3 全部完成）
- 成就解锁时弹出庆祝动画

### 日历打卡

- 日历视图直观展示打卡记录
- 支持补打卡（选择历史日期补签）
- 打卡日高亮标记

### 界面设计

- iOS 26 Liquid Glass 透明玻璃效果，10 层渲染结构
- 饱和度增强（1.6 倍 ColorMatrix），玻璃下颜色更鲜艳
- 锐利顶部高光 + 边缘 rim light/shadow + 颗粒感噪声纹理
- 深色 / 浅色模式无缝切换
- 色斑渐变背景，玻璃模糊有内容可透
- 低端设备自动降级，保证性能流畅

### 数据存储

- 纯本地 Hive 存储，无需联网，无需账号
- 学习进度、打卡记录、生词本、成就全部本地保存

## 本地运行

```bash
flutter pub get
flutter run
```

## 技术栈

- Flutter 3.10+
- Hive 本地存储
- audioplayers 音效播放
- flutter_tts 文字转语音

## 云端编译

项目配置了 GitHub Actions 自动编译：

- 推送到 `main` 分支后自动构建 APK 和 IPA
- 每次构建自动顺延版本号
- 构建完成后自动创建 GitHub Release 并上传安装包
- 也可在 [Actions 页面](../../actions) 手动触发
